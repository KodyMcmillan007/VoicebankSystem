This page is the set home page of the website, this website is created and designed to help others understand the systems known as a 'voicebank'; these systems are able to be tuned like that of an actual instrument to create music.

Voicebanks allow those who are either, too scared or unable to sing be granted the ability to actually sing. Well by using voicebanks that is, multipe different companys create these voicebanks; with producers of these voicebanks coming into light during the very start of when these types of voicebanks came into existence.

Voicebanks can be known as different sub-branches, like stated before this website allows others to understand each of these sub-branches by pulling data from a created and formated database. Throughout this website you will find links connected to other pages, each of these links will connect you to either areas such as this; where large amounts of text based infomation is laid out for you to learn about, or connect to pages which allow you pull from the database to understand the infomation you want to precisely understand at that time.
